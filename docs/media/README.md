# README media

Add your own demo assets here when they are ready. Suggested names:

- `scratch-demo.gif`: open, scratch and return in a short loop.
- `covers.png`: Plain and the six themed covers.
- `scratch-interaction.png`: a partly revealed photo.

Use a test chat and media you can publish. Keep original full-resolution recordings outside Git; small web-ready exports work better for the README.

Once `scratch-demo.gif` exists, add this under the introduction in both README files:

```md
![Scratch-to-reveal photo demo](docs/media/scratch-demo.gif)
```

There are intentionally no broken image placeholders or borrowed promotional screenshots in the current README.
