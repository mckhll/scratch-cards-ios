# Reporting a security issue

For a vulnerability introduced by this fork, contact the maintainer privately on Telegram: [@meeckhaill](https://t.me/meeckhaill). Include the affected commit, impact and minimal reproduction, without sharing login codes, active sessions or private signing keys.

For an issue in official Telegram, follow [Telegram's security reporting guidance](https://telegram.org/security). Ordinary rendering bugs and feature requests can be reported in this fork's public issues.

This is an experimental prototype; no response-time commitment or independent security audit is claimed.
